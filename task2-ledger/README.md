# Task 2 · 记账台账

> 用户故事:我一个人,在电脑上随手记日常开销,月底知道钱花哪了。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | **记账台账**(主交付):单文件网页应用,零依赖,双击即用 |
| `todo.html` | 待办事项应用(同风格单文件应用,作为补充保留) |

## 记账台账功能

- **随手记一笔**:金额 → 点分类 → 保存,两三秒完成一笔;支持备注与补记日期
- **8 个常用分类**:餐饮、交通、购物、居住、娱乐、医疗、学习、其他
- **月度概览**:本月总支出、记录笔数、日均支出
- **钱花哪了**:分类金额排行 + 占比条形图,一眼看出大头
- **本月流水**:按天分组(今天/昨天/具体日期),每笔可删除
- **翻月查看**:◀ ▶ 切换历史月份,随时回到本月
- **数据持久化**:保存在浏览器 localStorage,关闭页面不丢失

## 使用方式

直接双击 `index.html` 用浏览器打开即可,无需安装任何东西。
数据只存在本机浏览器中,换浏览器或清除浏览数据后不会保留。
